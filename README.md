# Onyekachi Uwasomba — Backend Developer Portfolio

A responsive portfolio website created for the BeTechified backend developer assignment. It presents the learning path and repository activity visible in the supplied GitHub screenshots, with direct links to the named repositories.

## Run locally

1. Download and extract this folder.
2. Open `index.html` in a modern browser.
3. Edit `index.html` for portfolio content, `styles.css` for visual design, and `script.js` for simple interactions.

No npm installation or build step is needed. The site uses Google Fonts when internet access is available; system fonts are the fallback.

## Download CV

The portfolio includes `Onyekachi_Uwasomba_Backend_Developer_CV.pdf`. The **Download CV** links in the navigation, introduction, and contact section open this file. Keep the PDF in the same directory as `index.html` when publishing the website (including through GitHub Pages).

An editable Word version can be maintained separately and exported to PDF when updated.

## Publish with GitHub Pages

1. Create a new public repository for the portfolio (for example `onyeka4jc.github.io` if available and intended for the personal site).
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the root of that repository.
3. Open **Settings → Pages**.
4. Choose deployment from the `main` branch and the `/ (root)` folder, then save.
5. Use only the URL shown by GitHub Pages after deployment completes. The portfolio has not been published by this package.
